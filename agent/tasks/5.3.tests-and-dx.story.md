# Story 5.3: 测试与开发体验

- 说明：建立基础测试覆盖，并保证可追踪的开发流程。

## 任务

1. 补充单元测试：状态机、Mock 仓库、轮询调度、反馈提交。
2. 补充 UI 测试：iOS 列表主流程，macOS 菜单栏主动作。
3. 编写任务级验收清单，映射到执行步骤。
4. 补充文档：`agent/requirements.md`、`agent/architecture.md` 与 tasks 交叉引用。

## 验收标准

- 至少覆盖核心用户路径。
- CI/本地可按统一命令验证。
- 文档与实现映射闭环。

## 开发任务清单（估时 / 优先级 / 阻塞项）

- T1：补充单元测试用例（状态机、仓库、轮询、反馈）（P1, 3h）
  - 阻塞项：Story 1、2 模块代码稳定。
- T2：补充 iOS UI 测试关键路径（列表更新、状态变更）（P1, 3h）
  - 阻塞项：可稳定运行的模拟器/真机环境。
- T3：补充 macOS UI 自动化场景（菜单栏打开/hover/展开）（P2, 2h）
  - 阻塞项：macOS UI 测试资源。
- T4：整理 `agent/requirements.md` 与 `agent/architecture.md` 到任务映射关系（P2, 1h）
  - 阻塞项：无。
- T5：建立验收清单模板（执行记录与回归标记）（P3, 1h）
  - 阻塞项：团队流程确认。
