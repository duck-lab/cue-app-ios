# Story 4.3: Menubar 未读徽标与主列表展开

- 说明：依据 `unread` 显示未读数量，支持点击展开完整列表。

## 任务

1. 在 `NSStatusItem` 上显示 badge 数值（按 `unread` 聚合）。
2. Badge 支持零时隐藏。
3. 点击图标从弹窗或 popover 切换到完整窗口。
4. 从完整窗口返回时保持状态一致。

## 验收标准

- 未读数准确展示。
- 点击行为可达完整通知列表。
- badge 与实际未读数据一致。

## 开发任务清单（估时 / 优先级 / 阻塞项）

- T1：计算 `unread` 聚合值并渲染到 status item badge（P1, 1h）
  - 阻塞项：依赖 Story 1.3 的未读定义。
- T2：实现 badge 0 值隐藏策略（P1, 0.5h）
  - 阻塞项：系统 API 支持范围确认。
- T3：实现点击 popover/窗口切换并维持状态同步（P1, 1.5h）
  - 阻塞项：与 Story 4.1 点击导航一致。
- T4：补充 badge 更新联动测试（P2, 1.5h）
  - 阻塞项：UI 自动化条件可用。
