# Story 3.3: iOS 系统通知快速回复

- 说明：当系统推送到达时，可直接在通知横幅中快速处理。
- 需求来源：`agent/requirements.md` 的 iOS 快速交互与已确认条目。

## 任务

1. 配置 `UNNotificationCategory` 与动作按钮（进行中、完成、忽略）。
2. 支持可选文本输入（回复或备注）。
3. 在通知 Action 回调中路由到统一 `ReplyUseCase`。
4. 处理前后台场景下的点击跳转与状态同步。

## 验收标准

- 系统通知可直接发起状态更新。
- 可选文本可随一次提交附加。
- 点击通知可回到对应条目上下文。

## 开发任务清单（估时 / 优先级 / 阻塞项）

- T1：配置 `UNNotificationCategory` 与 Action（进行中/完成/忽略）按钮（P1，2h）
  - 阻塞项：系统通知权限与注册时机。
- T2：接入文本输入 action（可选备注）（P2，1.5h）
  - 阻塞项：系统输入限制长度与键盘回调。
- T3：在 delegate 中路由到统一 `ReplyUseCase`（P1，2h）
  - 阻塞项：依赖 Story 2.4 的提交链路。
- T4：实现点击通知跳转到对应通知上下文（P2, 1h）
  - 阻塞项：深链接或选中态管理。
- T5：覆盖前后台触发场景测试（P2, 1.5h）
  - 阻塞项：真机测试条件可用。
