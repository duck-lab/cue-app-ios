# Story 3.1: iOS 通知列表与筛选排序

- 说明：提供可读、可操作、可筛选的通知列表。

## 任务

1. 构建主列表页面，支持按状态、优先级、来源分组/排序。
2. 显示标题、来源、时间、优先级、截止时间状态。
3. 支持下拉刷新（与轮询互补）。
4. 显示未读标记与状态标识。

## 验收标准

- 任何一条通知可在列表中清晰定位。
- 筛选/排序结果与选择条件一致。
- 首屏加载和状态更新动画平滑。

## 开发任务清单（估时 / 优先级 / 阻塞项）

- T1：搭建通知列表页面框架与数据绑定（P1，2h）
  - 阻塞项：依赖 Story 1.1/1.2/2.1 的模型与仓库。
- T2：实现列表展示内容（标题/来源/时间/优先级/截止时间）（P1，2h）
  - 阻塞项：无。
- T3：实现筛选与排序（状态、来源、优先级）（P2，2h）
  - 阻塞项：状态字段稳定。
- T4：下拉刷新与骨架状态（loading/empty/error）（P2，1h）
  - 阻塞项：刷新时机与轮询策略对齐。
- T5：列表交互体验优化（无障碍、可读性、动画）（P3，1h）
  - 阻塞项：设计样式确认。
