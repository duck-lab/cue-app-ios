# Epic 2: API 抽象与同步机制

- 目标：搭建可替换的 API/数据层，并实现 30 秒轮询刷新与反馈回传。
- 绑定需求：功能边界中的 Mock 优先、`30 秒`轮询、反馈回传需求。
- 验收标准：无 API 时可用 Mock 正常运行；后续替换为真实后端不影响上层业务逻辑。
