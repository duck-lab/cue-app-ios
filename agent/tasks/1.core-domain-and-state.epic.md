# Epic 1: 核心领域与数据模型

- 目标：定义通知应用的核心业务语义，建立可复用的领域模型。
- 绑定需求：需求说明中的「用户故事 > 通知接收与展示 / 通知处理」与「通知数据模型（v1）」
- 验收标准：应用内部有统一且稳定的通知对象模型，UI 与同步层均可基于同一状态语义运行。
- 计划输出：`NotificationItem`、`StatusFeedback`、`NotificationStatus` 等基础类型与状态转换策略。
