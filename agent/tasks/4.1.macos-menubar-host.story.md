# Story 4.1: macOS 菜单栏入口与窗口切换

- 说明：应用可最小化到菜单栏，点击后展开完整页面。

## 任务

1. 使用 `NSStatusItem` 构建菜单栏入口。
2. 点击菜单栏图标时展示/恢复完整窗口。
3. 应用支持最小化、切回主窗口的标准交互。
4. 与 iOS 状态一致展示同一份数据。

## 验收标准

- App 能在 macOS 上显示菜单栏图标。
- 点击菜单栏图标可打开完整通知列表。
- 列表与 iOS 的语义一致。

## 开发任务清单（估时 / 优先级 / 阻塞项）

- T1：创建 `NSStatusItem`，并接入主应用生命周期（P1，1.5h）
  - 阻塞项：确认 macOS target 的窗口展示方式。
- T2：实现点击展开完整窗口或弹窗的导航（P1，2h）
  - 阻塞项：与窗口管理框架兼容。
- T3：共享同一通知状态源，保证 iOS/Mac 数据口径一致（P1, 1h）
  - 阻塞项：依赖核心状态层完成。
- T4：菜单栏场景下的最小化/恢复行为回归测试（P2, 1.5h）
  - 阻塞项：测试环境支持。
