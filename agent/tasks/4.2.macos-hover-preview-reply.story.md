# Story 4.2: 菜单栏 Hover 预览与快速回复

- 说明：hover 显示最新通知，允许快捷操作与补充文本。
- 需求来源：已确认 macOS 菜单栏交互。

## 任务

1. 构建 hover 预览视图，展示最近一条未读或最近更新通知。
2. 提供三按钮操作：进行中、完成、忽略。
3. 提供可选的补充文本输入入口。
4. 操作成功后更新 badge 与列表数据。

## 验收标准

- hover 后能看到最新通知摘要。
- 三种动作在 hover 内可执行。
- 可选文本可附带提交。

## 开发任务清单（估时 / 优先级 / 阻塞项）

- T1：设计 hover 预览卡片布局与状态展示（P1，1.5h）
  - 阻塞项：依赖 Menubar 托管视图完成。
- T2：绑定最新通知查询逻辑（P1，1h）
  - 阻塞项：最新通知排序规则明确。
- T3：接入三类快速动作按钮（P1, 1.5h）
  - 阻塞项：依赖 Story 3.2 / 2.4。
- T4：接入可选文本输入组件（P2, 1h）
  - 阻塞项：输入焦点与 hover 退出行为处理。
- T5：动作成功后更新 hover 卡片和 badge（P2, 1h）
  - 阻塞项：与 Story 4.3 的 badge 更新一致。
